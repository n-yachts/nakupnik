Nápověda

Nákupník je sdílený nákupní seznam. Seznamů můžete mít víc (potraviny, drogerie, loď…) a každý můžete sdílet s rodinou nebo posádkou. Kdo je u obchodu, odškrtává; ostatní to za chvíli uvidí.

Seznamy se ukládají do Google Tabulek ve vašem Disku – žádný cizí server, nic se neplatí. Každý, s kým sdílíte, se přihlásí svým Google účtem.

Aplikace běží na n-yachts.github.io/nakupnik a dá se nainstalovat do telefonu.

První spuštění

Při prvním otevření vás provede průvodce. V Google Cloud je potřeba jednou povolit přístup k Tabulkám a Disku. Je to zdarma.

Používáte Lhůtník? Nákupník běží na stejné adrese n-yachts.github.io, takže použijete stejný projekt v Google Cloud i stejné Client ID (průvodce ho doplní sám). Stačí povolit tři API a vytvořit API klíč – kroky 2 a 5.

1. Projekt v Google Cloud

Máte-li projekt z Lhůtníku, v konzoli ho nahoře vyberte. Jinak založte nový přes vytvoření projektu (název třeba Nakupnik).

2. Povolte tři API

U každého klikněte na Povolit (Enable):

  • Google Drive API – zakládání a sdílení seznamů,
  • Google Sheets API – položky v tabulce,
  • Google Picker API – okno Google Disku pro otevření sdíleného seznamu.

3. Souhlasová obrazovka

S projektem z Lhůtníku je hotová. U nového projektu: v Google Auth Platform → Začít, název Nákupník, váš e-mail, cílová skupina Externí; pak v Audience Publikovat aplikaci.

Proč publikovat? V režimu Testing Google po 7 dnech zruší přihlášení a mohli by se přihlásit jen ručně přidaní testovací uživatelé. Publikovaná (neověřená) aplikace zvládne až 100 uživatelů; při přihlášení ukáže varování „Google tuto aplikaci neověřil“.

Volitelně v Data access přidejte oprávnění https://www.googleapis.com/auth/drive.file.

4. Client ID

V Clients otevřete klienta typu Webová aplikace (nebo ho vytvořte). V Authorized JavaScript origins mějte https://n-yachts.github.io a pro spouštění na počítači http://localhost:8081. Client ID vložte do průvodce – s Lhůtníkem je už předvyplněné.

5. API klíč

Okno Google Disku (Picker), přes které otevřete seznam, který vám někdo nasdílel, potřebuje API klíč:

  1. V Credentials klikněte na Create credentials → API key.
  2. Klíč omezte (Edit API key): Application restrictions → Websites: https://n-yachts.github.io/* a http://localhost:8081/*; API restrictions → Restrict key → Google Picker API. Uložte.
  3. Zkopírujte klíč (začíná AIza) a vložte ho do průvodce.

Díky omezení klíč nikdo jiný nevyužije. Ukládá se jen ve vašem prohlížeči.

6. Přihlášení

  1. Klikněte na Přihlásit se přes Google a vyberte účet.
  2. Při varování „Google tuto aplikaci neověřil“ klikněte na Pokračovat (případně Rozšířené → Přejít na …). Je to vaše vlastní aplikace.
  3. Povolte přístup „k souborům Disku, které s touto aplikací používáte“.

Přihlášení platí asi hodinu. Když vyprší, u názvu seznamu se objeví 🔑 Obnovit přihlášení – seznam mezitím dál funguje a změny počkají.

Seznamy

  • Nový seznam: + Nový seznam, napište název nebo klepněte na návrh (Potraviny, Drogerie, Loď…).
  • Otevření: klepněte na seznam. Nákupník si pamatuje poslední otevřený a příště začne v něm.
  • Zpět na přehled: šipka ← vlevo nahoře nebo logo Nákupník.
  • Další možnosti (tlačítko ⋯): přejmenovat, otevřít v Google Tabulkách, smazat koupené, smazat seznam.
Smazat, nebo odebrat? Váš vlastní seznam se smaže (přesune do koše Google Disku – zmizí i ostatním). U seznamu, který vám někdo nasdílel, je místo toho Odebrat z mých seznamů – zmizí jen vám.

Přidávání položek

Napište položku do pole nahoře a stiskněte Enter (nebo Přidat). Množství můžete napsat před i za název:

NapíšeteUloží se
2 l mléko nebo mléko 2lMléko · 2 l
rohlíky 10Rohlíky · 10 ks
3x jogurtJogurt · 3 ks
1,5 kg bramboryBrambory · 1,5 kg
20 dkg šunkyŠunky · 20 dkg
másloMáslo (bez množství)

Jednotky: ks, kg, dkg, g, l, ml, bal (balení). Číslo bez jednotky znamená kusy.

  • Oddělení se určí samo podle názvu (mléko → Mléčné a vejce, zubní pasta → Drogerie…). Když se netrefí, změňte ho v úpravě položky – příště si ho Nákupník pamatuje.
  • Stejná položka se nepřidá dvakrát: když už na seznamu je, jen se upraví množství; když je v košíku, vrátí se zpět do seznamu.
  • Často kupujete: pod polem jsou položky, které kupujete nejčastěji – klepnutím je přidáte. Při psaní se nabízejí i dříve kupované položky.

Nakupování

Položky jsou seřazené podle oddělení v pořadí, v jakém obvykle procházíte obchodem: ovoce a zelenina, pečivo, mléčné, maso, trvanlivé, mražené, sladkosti, nápoje, drogerie, domácnost, zvířata, ostatní.

  • Koupeno: klepněte na kroužek vlevo. Položka se přesune do 🧺 V košíku. Omylem? Klepněte na ni v košíku znovu.
  • Úprava: klepněte na název – můžete změnit množství, jednotku, oddělení nebo přidat poznámku (značka, „bez laktózy“…). Je tu i Smazat.
  • Po nákupu: Smazat koupené ze seznamu vyčistí košík. Položky zůstanou v „Často kupujete“.
  • U sdíleného seznamu je vpravo vidět, kdo položku přidal.

Sdílení

Nasdílet seznam

  1. V seznamu klepněte na 👥 Sdílet.
  2. Napište e-mail Google účtu (manželka, posádka…) a klepněte na Sdílet.
  3. Dotyčnému přijde e-mail od Googlu s odkazem na Nákupník.

V okně sdílení vidíte, kdo má přístup, a jako vlastník ho můžete odebrat. Je tam i odkaz na seznam, který můžete poslat třeba přes WhatsApp – funguje ale jen lidem, se kterými je seznam sdílený.

Otevřít seznam, který vám někdo nasdílel

Nákupník má přístup jen k tabulkám, které mu výslovně ukážete. Proto je potřeba sdílený seznam jednou potvrdit v okně Google Disku:

  1. Otevřete odkaz z e-mailu (nebo v přehledu klepněte na 📥 Otevřít sdílený).
  2. Klepněte na Zpřístupnit seznam. Otevře se okno Google Disku se seznamem.
  3. Vyberte ho a klepněte na Vybrat. Hotovo – seznam už máte mezi svými natrvalo.
Seznam v okně nevidíte? Zkontrolujte, že jste v Nákupníku přihlášeni stejným účtem, na jehož e-mail byl seznam sdílen.

Ukládání a bez signálu

Pod názvem seznamu je vidět stav:

✓ Uloženo · právě teďvše je v Google Tabulce
⟳ Ukládám…změny se právě odesílají
📶 Offline · ⏳ 1 změna čekábez signálu – změny počkají v telefonu a odešlou se po připojení
🔑 Obnovit přihlášenípřihlášení vypršelo – klepněte; změny mezitím čekají
  • Změny od ostatních se načítají každých 15 sekund, když máte seznam otevřený, a hned po návratu do aplikace.
  • Seznam se ukládá i do telefonu, takže ve sklepě supermarketu bez signálu ho pořád vidíte a můžete odškrtávat.
  • Když dva lidé změní stejnou položku současně, platí poslední změna.

V Google Tabulkách

Každý seznam je Google Tabulka „Nákupník – název“ ve vašem Disku (menu ⋯ → Otevřít v Google Tabulkách). List Položky má sloupce: id, položka, množství, jednotka, kategorie, koupeno, poznámka, přidal, změněno. List Historie slouží pro „Často kupujete“.

Tabulku raději neupravujte ručně. Nepřejmenovávejte listy ani nemažte sloupec id – podle něj Nákupník položky poznává. Přidat řádek ručně jde, jen vyplňte jedinečné id.

Instalace do telefonu

  • Android (Chrome): tlačítko 📲 Nainstalovat v aplikaci, nebo menu ⋮ → Nainstalovat aplikaci.
  • iPhone (Safari): Sdílet → Přidat na plochu (Client ID a API klíč bude potřeba zadat znovu).
  • Počítač: ikona instalace v adresním řádku Chromu nebo Edge.

Aplikace se přizpůsobí i tmavému režimu.

Řešení potíží

Nevidím novou verzi

Načtěte stránku znovu s Ctrl+Shift+R, v telefonu aplikaci zavřete a otevřete. Verzi vidíte v Nastavení.

„V Google Cloud není povolené Google Drive API“

API je potřeba povolit ve stejném projektu, ke kterému patří Client ID (číslo projektu je v hlášce i na začátku Client ID). Zkontrolujte, že máte nahoře v konzoli vybraný správný projekt, a povolte Drive API, Sheets API a Picker API. Po povolení počkejte pár minut. Vaše seznamy ani změny se mezitím neztratí.

Google Picker API není v omezeních API klíče

V nabídce API restrictions se ukazují jen povolená API – nejdřív Picker API povolte a stránku klíče obnovte. Případně zvolte Don't restrict key a nechte jen omezení na weby.

Chyba origin_mismatch

V Client ID chybí https://n-yachts.github.io (nebo http://localhost:8081) v Authorized JavaScript origins.

Okno Google Disku se neotevře nebo hlásí chybu

Zkontrolujte, že je povolené Google Picker API a že API klíč má v omezeních adresu https://n-yachts.github.io/* a API Google Picker API. Klíč změníte přes Nastavení → Znovu spustit průvodce.

„K seznamu už nemáte přístup“

Vlastník seznam smazal nebo vám odebral sdílení. Seznam zmizí z vašeho přehledu.

Kamarád nemůže přihlásit (access_denied)

Aplikace je v Google Cloud v režimu Testing. Publikujte ji (krok 3), nebo ho přidejte mezi Test users.

Položka je ve špatném oddělení

Klepněte na ni a oddělení změňte. Příště ho Nákupník u stejné položky použije.

Soukromí a oprávnění

Nákupník žádá jen oprávnění drive.file – vidí a mění jen tabulky, které sám založil, nebo které mu ukážete v okně Google Disku. Ostatní soubory ve vašem Disku nevidí.

Data jsou jen v Google Tabulkách a v mezipaměti vašeho prohlížeče. Aplikace nemá server a nic nesleduje. Přístup odeberete v nastavení Google účtu.
